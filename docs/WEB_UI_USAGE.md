# Web 界面使用说明

## 访问方式

服务启动后，通过浏览器访问：
- 主页：`http://your-server:5000/`
- 或：`http://your-server:5000/index.html`

## 功能特性

### 1. 文件上传
支持三种上传方式：
- **点击上传**：点击上传区域，选择文件
- **拖拽上传**：将文件拖拽到上传区域
- **粘贴上传**：按 `Ctrl+V` 粘贴剪贴板中的图片

支持的文件格式：
- 图片：JPG, PNG, BMP, TIFF 等
- 文档：PDF（支持多页）

### 2. 预览功能

**图片预览：**
- 显示原始图片
- 在图片上标注 OCR 识别的文本块（蓝色半透明框）
- 鼠标悬浮文本块时高亮显示（绿色）

**PDF 预览：**
- 使用 PDF.js 渲染 PDF 页面
- 每页显示页码标识
- 支持滚动查看多页
- 在每页上标注 OCR 识别的文本块

### 3. 识别结果

**完整文本区域：**
- 显示所有识别的文本内容
- 支持滚动查看长文本
- 点击"复制全部"按钮一键复制全部文本

**OCR 结果表格：**
- 显示每个文本块的详细信息：
  - 序号
  - 页码（仅 PDF）
  - 文本内容
  - 置信度（百分比）
- 点击文本内容可单独复制该段文字
- 鼠标悬浮表格行时，预览区域对应的文本块会高亮显示

### 4. 双向高亮

Web 界面支持预览区和结果表格的双向交互：
- **预览区 → 表格**：鼠标悬浮在预览区的文本块上时，表格中对应行会高亮
- **表格 → 预览区**：鼠标悬浮在表格行上时，预览区对应的文本块会高亮

### 5. API Key 配置

如果服务端设置了 `API_KEY` 环境变量：
1. 页面顶部会显示 "API Key" 输入框
2. 输入正确的 API Key
3. API Key 会自动保存在浏览器 localStorage 中
4. 下次访问无需重新输入

## 使用流程

1. **打开页面**：访问 `http://your-server:5000/`
2. **配置 API Key**（可选）：如果服务端启用了认证，输入 API Key
3. **上传文件**：通过点击、拖拽或 Ctrl+V 上传图片或 PDF
4. **等待识别**：页面显示"正在识别中，请稍候..."
5. **查看结果**：
   - 左侧：文件预览 + 文本块标注
   - 右侧：完整文本 + OCR 结果表格
6. **复制文本**：
   - 点击"复制全部"按钮复制所有文本
   - 点击表格中的文本内容复制单段文字

## 响应式设计

Web 界面支持多种设备：
- **桌面端**：双栏布局，预览和结果并排显示
- **平板/手机**：单栏布局，自动适配小屏幕

## 技术栈

- **前端框架**：Vue 3 (UMD)
- **PDF 渲染**：PDF.js
- **剪贴板**：Clipboard.js
- **提示通知**：Toastify.js
- **加载方式**：CDN（无需本地构建）

## 注意事项

1. **大文件上传**：
   - 默认最大文件大小为 20MB
   - 大 PDF 文件可能需要较长识别时间

2. **浏览器兼容性**：
   - 建议使用现代浏览器（Chrome, Firefox, Edge, Safari）
   - 需要支持 ES6+ 特性

3. **网络要求**：
   - 首次加载需要从 CDN 下载 JS 库
   - 建议良好的网络环境以获得最佳体验

4. **隐私安全**：
   - 上传的文件会发送到服务器进行 OCR 识别
   - 确保在可信的网络环境中使用
   - 服务端会自动清理临时文件

## 快捷键

- `Ctrl+V`：粘贴剪贴板中的图片并识别

## 开发调试

如需修改界面：
1. 编辑 `static/index.html`（HTML 和 CSS）
2. 编辑 `static/app.js`（JavaScript 逻辑）
3. 重启服务即可生效（无需构建）
